# HW: Hardware Trojan Lab

## Folder contents

| File | Description |
|---|---|
| `Hardware_Trojan_Insertion_Lab.ipynb` | Executed notebook with Tasks 1–4 output |
| `detector.py` | Heuristic Trojan detector (Task 5) |
| `summary.csv` | Batch analysis table generated by Task 3 |
| `validation_log.txt` | Per-file validation results from Task 4 |
| `report.pdf` | 1–2 page report covering all tasks |
| `batch_trojan_designs/` | Generated trojaned Verilog samples (T1, T2 via gpt-4o) |
| `demo_designs/` | Clean baseline Verilog designs used as generation inputs |
| `GHOST_Trojan_GPT.py` | GHOST Trojan insertion tool (generation pipeline) |
| `generate_trojan_outputs.py` | Script that produces the pre-built trojaned samples |

## How to reproduce

### Run the analysis (no API key needed)
```bash
# From the HW_HardwareTrojanLab/ directory:

# Tasks 3 & 4 — generates summary.csv and validation_log.txt
jupyter nbconvert --to notebook --execute Hardware_Trojan_Insertion_Lab.ipynb

# Task 5 — runs heuristic detector, prints evaluation table, writes summary.csv
python detector.py
```

### Regenerate trojaned samples (requires OpenAI API key)
```bash
set -a; source .env; set +a   # .env must contain OPENAI_API_KEY=... (not committed)

python GHOST_Trojan_GPT.py \
  --backend OpenAI \
  --model gpt-4o \
  --design demo_designs/alu_simple.v \
  --output-dir batch_trojan_designs \
  --vulnerabilities T1 T2 \
  --attempts 3
```

## Safety statement

All generated designs are synthetic RTL benchmarks for defensive research only.
No API keys are committed. `RUN_BATCH_JOB` and `RUN_BATCH` are set to `False`
in the notebook. Generated trojaned outputs are never deployed in real systems.
