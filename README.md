# HW: Hardware Trojan Lab

## Folder contents

| File | Description |
|---|---|
| `Hardware_Trojan_Insertion_Lab.ipynb` | Executed notebook with Tasks 1–4 output |
| `detector.py` | Heuristic Trojan detector (Task 5) |
| `summary.csv` | Batch analysis table generated by Task 3 |
| `validation_log.txt` | Per-file validation results from Task 4 |
| `report.pdf` | 1–2 page report covering all tasks |
| `batch_trojan_designs/` | Generated trojaned Verilog samples |

## How to reproduce

```bash
# From the HW_HardwareTrojanLab/ directory:
set -a; source ../.env; set +a

# Run the notebook (Tasks 3 & 4 generate summary.csv and validation_log.txt)
jupyter nbconvert --to notebook --execute Hardware_Trojan_Insertion_Lab.ipynb

# Run detector evaluation
python detector.py
```

## Safety statement

All generated designs are synthetic RTL benchmarks for defensive research only.
No API keys are committed. `RUN_BATCH_JOB` and `RUN_BATCH` are set to `False`
in the notebook. Generated trojaned outputs are never deployed in real systems.
