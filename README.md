## How to reproduce

### Run the analysis (no API key needed)
```bash
# From the HW_HardwareTrojanLab/ directory:

# Tasks 3 & 4 — generates summary.csv and validation_log.txt
jupyter nbconvert --to notebook --execute Hardware_Trojan_Insertion_Lab.ipynb

# Task 5 — runs heuristic detector, prints evaluation table, writes summary.csv
python detector.py
```

### Regenerate trojaned samples (requires OpenAI API key)
```bash
set -a; source .env; set +a   # .env must contain OPENAI_API_KEY=... (not committed)

# alu_simple — all four vulnerability types
python GHOST_Trojan_GPT.py \
  --backend OpenAI --model gpt-4o \
  --design demo_designs/alu_simple.v \
  --output-dir batch_trojan_designs \
  --vulnerabilities T1 T2 T3 T4 \
  --attempts 3

# shift_reg — T3 and T4 only
python GHOST_Trojan_GPT.py \
  --backend OpenAI --model gpt-4o \
  --design demo_designs/shift_reg.v \
  --output-dir batch_trojan_designs \
  --vulnerabilities T3 T4 \
  --attempts 3
```

## Detector heuristics

`detector.py` flags seven patterns, each targeting one or more vulnerability types:

| Flag | Targets | What it matches |
|---|---|---|
| `trojan_marker` | T1–T4 | `"trojan"` anywhere in the file (header comment) |
| `internal_counter` | T1/T3/T4 | Counter variable name or `<= x + 1` increments |
| `magic_constant` | T1/T2/T3 | Specific value comparisons used as rare triggers |
| `conditional_payload` | T1/T2/T3 | `if` block gated by trigger signal or magic value |
| `suspicious_logic` | T1/T2 | Known payload patterns, `trojan_insertion_begin` marker |
| `stall_mechanism` | T3 | `stall` register, forced `result <= 8'b0` output |
| `power_waste` | T4 | Toggle assignment (`<= ~reg`), idle activity registers |

Threshold: score ≥ 2 → suspicious. Results on current sample set: **18/18 TP, 0 FP** (precision 1.00, recall 1.00).
